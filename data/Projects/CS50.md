## Overview

**CS50x** is Harvard University's introduction to computer science and the art of programming. More than just teaching syntax in one language, the course focuses on the foundations of problem solving, computational thinking, and how to learn new technologies independently. It begins with **C** to teach memory, pointers, and systems-level thinking, then transitions into **Python**, **SQL**, **HTML**, **CSS**, **JavaScript**, and **Flask** for higher-level application development.

## What I'm Learning

Through CS50, I’ve been building a stronger foundation in core computer science concepts such as:

- algorithms
- data structures
- abstraction
- memory management
- systems programming
- backend and frontend web development

The course has helped me understand not only how to write code, but also how computers work underneath the hood and how to apply those principles to real-world software engineering problems.

## What I've Built

Across the course, I’ve completed projects and assignments using **C**, **Python**, **SQL**, **HTML/CSS**, **JavaScript**, and **Flask**. These projects include command-line programs, database-backed applications, and fully functional web apps with frontend interfaces, backend logic, and persistent data. I am also currently working toward the course’s final capstone project, which is giving me the opportunity to apply the full stack of concepts in one end-to-end build.

## Why It Matters

CS50 has been especially valuable because it connects low-level programming concepts with modern application development. Starting in **C** built a much stronger understanding of memory, performance, and program structure, while the later transition into web development showed how those fundamentals carry into practical, user-facing applications. The course has made me more confident in both building software and learning new tools independently.
