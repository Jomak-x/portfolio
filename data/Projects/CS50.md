**CS50x** has been one of the most important foundations in my growth as an engineer because it pushed me to understand not just how to write code, but how software actually works underneath the surface. Through Harvard's introduction to computer science, I have been working through core topics like algorithms, data structures, memory management, systems programming, and the broader habits of computational problem solving.

What I appreciate most about the course is its progression. It starts in **C**, where you are forced to think carefully about memory, pointers, and program structure, and then expands into **Python**, **SQL**, **HTML**, **CSS**, **JavaScript**, and **Flask**. That path makes the jump from low-level reasoning to full-stack application development feel intentional instead of disconnected.

Across the course, I have built command-line programs, database-backed applications, and full web projects with backend logic and responsive frontends. I am currently working toward the final capstone, where the goal is to pull those skills together into one end-to-end build that reflects a full software engineering workflow rather than a series of isolated exercises.

## Highlights

- **Strong CS foundations** in algorithms, data structures, memory management, and systems programming
- **End-to-end projects** built across C, Python, SQL, HTML/CSS, JavaScript, and Flask
- **Practical full-stack experience** connecting frontend interfaces, backend logic, and databases
- **Currently in progress**, culminating in a final capstone project
